Sobre o projeto

Um projeto independente

Ferramenta independente que reúne dados públicos de fontes oficiais para facilitar a consulta. Não tem vínculo com a prefeitura, não substitui os canais oficiais e não tem viés político, as interpretações são geradas automaticamente por IA, não opinião do projeto.
