Sobre o projeto

Um projeto independente

O Arcos Transparente é uma ferramenta independente que utiliza dados públicos disponíveis em fontes oficiais, como o Portal da Transparência, para facilitar a consulta e compreensão das informações municipais. O projeto não substitui os canais oficiais. As respostas procuram indicar a fonte dos dados utilizados e deixar claro quando a informação não está disponível ou é limitada.

Este projeto não tem viés político. Não foi criado para atacar nem para defender ninguém. A ideia é simplesmente facilitar o acesso público às informações da cidade.

Consultar dados públicos é um direito seu.

A Lei de Acesso à Informação garante que qualquer cidadão possa acessar informações públicas. O Arcos Transparente ajuda a tornar esse caminho mais simples, aproximando os dados oficiais da população.
